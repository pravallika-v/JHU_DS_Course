# Course 1: The Data Scientist's Toolbox

Focus of this course: install and connect the core tools, then practice a tiny project workflow.

## Checklist

- [ ] Install R
- [ ] Install RStudio
- [ ] Confirm Git works in a terminal (`git --version`)
- [ ] Create a GitHub account
- [ ] Create a GitHub repo for Course 1
- [ ] Link local folder ↔ GitHub (clone or `git init` + remote)
- [ ] Write a short README in that repo
- [ ] Make a first commit and push

## Concepts to watch for

- What data science is (questions → data → analysis → communication)
- Types of data science questions (descriptive, exploratory, inferential, predictive, causal, mechanistic)
- Why version control matters
- Markdown basics for READMEs
