# Johns Hopkins Data Science Specialization

Workspace for the [Coursera Data Science Specialization](https://www.coursera.org/specializations/jhu-data-science) (JHU: Peng, Caffo, Leek).

This series is built around **R**, RStudio, Git/GitHub, and the full data science pipeline.

Each course folder has:

- `notes/` – lecture summaries, concepts, quiz review
- `assignments/` – peer-graded work, scripts, reports (your own solutions)
- `practice/` – experiments, swirl follow-ups, small drills

Shared assets go in `shared/datasets` and `shared/snippets`.

## How to use this with Cursor

Paste a lecture idea, quiz topic, error message, or assignment prompt into chat and ask for:

- a plain-language explanation
- a small R example to try
- help debugging your script
- a study checklist for the week

Do **not** paste graded answers you did not write yourself into shared repos if that would violate Coursera honor code. Keep assignment solutions private unless the course allows sharing.

## Local setup (Course 1)

Course 1 walks through installing the tools. On this machine:

- **Git** is installed (`git 2.34.1`)
- **R / RStudio** are not installed yet

Install when you are ready:

1. [R](https://cran.r-project.org/)
2. [RStudio Desktop](https://posit.co/download/rstudio-desktop/)
3. A [GitHub](https://github.com/) account (Course 1 creates a repo)

Optional later: open this folder as an RStudio project, or keep editing `.R` / `.Rmd` files here in Cursor.
